ポケカ カードJSON変換

公式のカード詳細ページから、カードデータをJSONにします。公式サイトへの負荷を避けるため、必要なカードだけを1秒間隔で取得します。

リンク取得が失敗するとき（CORS）

ブラウザから公式サイトへ直接fetchすると、CORSで拒否されることがあります。その場合は、上の貼り付け欄を使うか、Cloudflare Workers（無料枠）に次のコードを置き、そのURLを「プロキシURL」に入れてください。

export default {
  async fetch(req) {
    const u = new URL(req.url).searchParams.get("url");
    if (!u || !u.startsWith("https://www.pokemon-card.com/"))
      return new Response("ng", { status: 400 });
    const r = await fetch(u);
    return new Response(r.body, { status: r.status, headers: {
      "content-type": "text/html; charset=utf-8",
      "access-control-allow-origin": "*" } });
  }
};

IDだけを入れた場合は regu/all のURLで取得します。進化元は、現在のカードの1つ下の進化グループから推定した値です。
